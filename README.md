# GitHub Guide

A step-by-step guide for new joiners to learn GitHub — from cloning a repository to creating a Pull Request.

## What's Inside

- [**GitHub Guide**](docs/github-guide.md) — Complete walkthrough covering:
  - Git installation and configuration
  - SSH authentication setup
  - Cloning repositories
  - Branching, staging, committing, and pushing
  - Creating and managing Pull Requests (Web UI + CLI)
  - Reviewing PRs, handling feedback, and merging
  - Quick reference table and common pitfalls

## Getting Started

Start with the [full guide](docs/github-guide.md) and follow along step by step.

If you're using [Claude Code](https://claude.com/claude-code), you can also run `/github-guide` for an interactive walkthrough.
